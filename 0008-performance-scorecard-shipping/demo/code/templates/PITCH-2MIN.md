# 2-minute pitch: five parts

| Seconds | Part | One sentence to write |
|---|---|---|
| 0 to 20 | Problem | "<Who> loses <what> because <why>." |
| 20 to 50 | What it does | "<Project> does <one thing>." Show the demo or one screenshot. |
| 50 to 80 | Evidence | "Tests pass: <N>. On devnet: <explorer link>. Output: <number>." |
| 80 to 105 | Limit | "It does not <X>, so <Y>." |
| 105 to 120 | Ask | "Run it: <repo>. Next I will <Z>." |

What judges look at: utility, tests, devnet evidence. Not simulated returns: never quote a return as a result.
