# Demo script (3 minutes)

Rehearse it twice with a timer. Say the sentences, do not read them.

1. **Problem (20 s).** Who has it, in one sentence, with a concrete example.
2. **Run (60 s).** The exact command. Say what to look at BEFORE you press enter.
3. **Evidence (40 s).** One of: a passing test run, a devnet explorer link, a scorecard number. Show it, do not describe it.
4. **Limit (30 s).** One thing it does not do. Judges trust projects that name their own limit.
5. **Next (20 s).** One concrete next step.
