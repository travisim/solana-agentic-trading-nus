# Workshop 4 demo repo: Performance Scorecard and Shipping

- `code/`: TypeScript sample code (Node 24). `npm install`, `npm test`, `npm run demo -- --recorded`, `npm run ship-check -- <folder>`, `npm run smoke`. Start with `code/README.md`.
- `lab/`: five interactive demos (open `lab/index.html`). Each has a Recorded/Live switch.

Reads use public mainnet data; every write is devnet only; no real funds, no seed phrases, no keys, no AI credits. Simulated results are on recorded data and are not advice.
