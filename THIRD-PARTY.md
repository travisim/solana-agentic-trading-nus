# Third-party data, services and licences

- **Jupiter** public quote API (`lite-api.jup.ag`): quotes read at capture time; subject to Jupiter's terms. No key is bundled.
- **Pyth Network** price accounts: read on-chain through public Solana RPC (the Hermes REST API is not used). Recorded values are included for teaching.
- **Orca Whirlpools**: on-chain pool accounts and swap transactions read through public RPC. The Orca SDK is not bundled; its licence is non-commercial with a university-course allowance, so check it before using the SDK.
- **Solana public RPC**: rate-limited; use your own endpoint for heavy use.
- **Solana logo and brand**: used in the workshop slides under the Solana Foundation branding guidelines (https://solana.com/branding); not part of this repository's licence.
- **Fonts**: Helvetica Neue is a system font and is not distributed; demos fall back to system sans-serif.
- Recorded data was captured on the dates in each `code/recorded/SOURCES.md` and is provided for education only.

Nothing here is financial advice. Simulated results on recorded data do not predict real results.
